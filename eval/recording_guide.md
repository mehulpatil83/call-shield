# Recording guide (for people helping with the evaluation)

Thank you for helping. You will read short fictional scripts aloud. Nothing here is real: no real names, accounts or numbers.

## What happens to your recording
- It is saved on the project owner's computer only, in a folder that is not uploaded to GitHub.
- It is sent to Gnani's speech-to-text service to be transcribed (that is how the project works).
- It is used only to test this project. It is not published, and it will be deleted when the project is finished
  (ask for it to be deleted at any time).
- You may say no, or stop, at any time.

## Please confirm (reply to the project owner, or say it at the start of the first recording)
"I agree to record these fictional scripts for testing call-shield, and I understand how the audio will be used."

## How to record
- Use your phone's voice recorder (or Audacity on a computer). A quiet room is best; one or two scripts in a noisier
  place (street, fan, kitchen) are useful too: add `n` after the speaker name, e.g. `p1n_en-s1.wav`.
- Hold the phone as you would for a call, speak normally and clearly, one script per file, 20 to 40 seconds.
- Read the script as written. If you stumble, record it again.
- Save as WAV if you can, otherwise M4A or MP3.

## File names
`<your short id>_<script id>.wav`, for example `p2_mr-s1.wav`. The script ids are printed next to each script
(en-s1, hinglish-b2, mr-b3, ...). Do not rename anything else.

## Which scripts
Please record as many as you comfortably can, in the language(s) you speak. 8 scripts per language is ideal.
For Marathi and Hinglish, tell the project owner if any line sounds unnatural: the texts are drafts and your correction helps.
